# Contract addresses

**Audience:** dev integrating via ABI + on-chain address.
**Prerequisites:** none.

## Addresses per network

### Localhost (hardhat node)

Deploy via `npx hardhat ignition deploy ./ignition/modules/Dao.ts --parameters ignition/parameters/dev.json --network localhost`. Addresses are deterministic based on Ignition's deploy order, but vary with the deployer's nonce. Use the deploy output.

The remodel contracts (CreditPSM, FeeRouterV2, ProjectFunding) + dev mocks are deployed by `scripts/deploy-remodel.ts` and live in:

```
ignition/deployments/chain-31337/dev_addresses.json
```

> ⚠️ **Dev only — changes on every deploy.** The hardhat node is in-memory: every restart wipes the chain and every redeploy generates new addresses. Never hardcode; always read from the JSON (or from the `/config.json` served by the frontend). Current keys: `USDC` (mock), `DevSwapPool`, `CreditPriceOracle`, `DevFaucet`, `CreditPSM`, `ProjectFunding`, `FeeRouterV2`.

## ABIs

ABIs are generated by Hardhat in `artifacts/contracts/*.sol/*.json`. Each JSON contains the `abi` field.

For TypeScript/Vue apps, use the frontend's `sync-contracts.ts` script (already integrated in `/home/ubuntu/web3community-frontend/`) that copies ABIs + typechain types.

## Token addresses (after deploy)

To discover GOV and CREDIT addresses after deploy:

```typescript
const deployed = require('./ignition/deployments/chain-<chainId>/deployed_addresses.json');
const GOV    = deployed['CommunityDAOModule#GovernanceToken'];
const CREDIT = deployed['CommunityDAOModule#CreditToken'];
const TREASURY = deployed['CommunityDAOModule#Treasury'];
const REGISTRY = deployed['CommunityDAOModule#ProjectRegistry'];
const STAKING = deployed['CommunityDAOModule#Staking'];
const BURN_TRACKER = deployed['CommunityDAOModule#BurnTracker'];
const REWARD_DISTRIBUTOR = deployed['CommunityDAOModule#RewardDistributor'];
const FEE_ROUTER = deployed['CommunityDAOModule#FeeRouter'];
const TIMELOCK = deployed['CommunityDAOModule#CommunityTimelock'];
const GOVERNOR = deployed['CommunityDAOModule#CommunityGovernor'];
```

For the remodel contracts on the local network (dev, changes on every deploy):

```typescript
const dev = require('./ignition/deployments/chain-31337/dev_addresses.json');
const PSM           = dev['CreditPSM'];
const FEE_ROUTER_V2 = dev['FeeRouterV2'];
const FUNDING       = dev['ProjectFunding'];
const USDC_MOCK     = dev['USDC'];
```

## Contracts not deployed by the main module

`TeamVesting` and `UserSubsidy` have separate Ignition modules (`ignition/modules/TeamVesting.ts` and `ignition/modules/UserSubsidy.ts`) — deployed on demand via DAO proposal, not at bootstrap.

Each `TeamVesting` is a separate instance (one per beneficiary). Their addresses live in dedicated deployments.

## On-chain verification

After deploy on a public network:

```bash
npx hardhat verify --network sepolia <contract_address> <constructor_args>
```

Constructor args can be extracted from `ignition/parameters/production.json` + automated derivations of the module.
